# Быстрый старт: перенос трекера в другой проект

Пошаговая инструкция «скопировал → работает». Трекер самодостаточен: база, схема, каталоги
и MCP-сервер создаются автоматически, ручных SQL и файлов не нужно.

---

## Шаг 0. Что нужно

- **Node.js ≥ 22.5** (используется встроенный `node:sqlite`). Проверка: `node --version`.
- Доступ в интернет только на шаге установки зависимостей.

## Шаг 1. Скопировать каталог

Скопируй папку `simple-ai-tracker` (в этом репозитории — `apps/simple-ai-tracker`) в новый проект,
например в `<новый проект>/tools/simple-ai-tracker` или сразу в отдельный репозиторий.

Копировать нужно **без** `node_modules`, `dist`, `data`, `export` — эти каталоги создаются локально.
Если переносишь существующие задачи — скопируй ещё и `data/tracker.db` (или сделай бэкап / `export:json`).

## Шаг 2. Установить зависимости

```bash
cd simple-ai-tracker
npm install --omit=dev     # только MCP: SDK + esbuild (~15 МБ)
# или
npm install                # MCP + веб-интерфейс (Angular, ~400 МБ)
```

`--omit=dev` достаточно, если нужен **только MCP-доступ** (агент работает через инструменты `tracker_*`).

## Шаг 3. Проверить установку

```bash
npm run doctor
```

Покажет: версию Node, корень приложения, путь к базе (и что она создана), версию схемы, число задач,
собран ли UI и MCP-бандл, найден ли файл инструкции, настройки бэкапов.

База создаётся автоматически при **первом** запуске любого из компонентов (CLI, API или MCP):
`data/tracker.db` + все таблицы и FTS-индекс. Ничего инициализировать вручную не нужно.

## Шаг 4. Подключить MCP к агенту

Добавь сервер в конфигурацию MCP-клиента проекта-потребителя (Cursor / Claude Desktop / DSH и т.п.):

```json
{
  "mcpServers": {
    "simple-ai-tracker": {
      "command": "node",
      "args": ["<путь до simple-ai-tracker>/scripts/mcp-launcher.mjs"]
    }
  }
}
```

`mcp-launcher.mjs` сам соберёт бандл при первом запуске (и пересоберёт, если исходники новее) —
отдельный `npm run build:server` не обязателен.

## Шаг 5. Скопировать правила для агента

Открой [`AGENT_INSTRUCTIONS.md`](AGENT_INSTRUCTIONS.md) и вставь раздел
**«Правила работы с тасктрекером»** в инструкцию проекта (`AGENTS.md`, `CLAUDE.md`, правила Cursor).

После этого агент, увидев правила, работает с задачами **только через MCP**: `tracker_get_task`,
`tracker_ask_questions`, `tracker_attach_plan`, `tracker_record_clarification` и остальные —
без `grep`, чтения файлов задач и прямых запросов к базе.

## Шаг 6. Запустить веб-интерфейс (по желанию)

```bash
npm run build:web    # только при полной установке (npm install без --omit=dev)
npm start            # http://127.0.0.1:4317 — доска и REST API
```

Dev-режим с hot-reload: `npm run dev:api` + `npm run serve:web` (UI на 4318, прокси на 4317).

## Шаг 7. Создать первую задачу

- **Через UI:** кнопка «+ Задача» в тулбаре (ID будет `SAT-1`, `SAT-2`, …).
- **Через агента:** попроси «создай задачу: …» — он вызовет `tracker_create_task`.
- **Через CLI-импорт**, если переносишь старый JSON-бэклог:

```bash
npm run import:json -- --source <каталог с tasks.json и tasks/>
```

## Куда что пишется

| Что | Где | В git |
|---|---|---|
| База задач | `data/tracker.db` (+ `-wal`, `-shm` во время работы) | нет (`.gitignore`) |
| Бэкапы | `data/backups/tracker-YYYY-MM-DD_HH-mm-ss.db` | нет |
| Экспорт карточек | `export/` (по `npm run export:json`) | нет |
| Сборка | `dist/server/*.mjs`, `dist/web/` | нет |
| Инструкция для агента | `AGENT_INSTRUCTIONS.md` | **да** |

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что меняет |
|---|---|---|
| `SAT_DB_PATH` | `data/tracker.db` | путь к базе (можно вынести в общий каталог) |
| `SAT_PORT` / `SAT_HOST` | `4317` / `127.0.0.1` | адрес UI и REST |
| `SAT_ID_PREFIX` | `SAT` | префикс ID новых задач |
| `SAT_BACKUP_ENABLED` | `true` | авто-бэкапы: старт + интервал, не чаще лимита в сутки |
| `SAT_BACKUP_INTERVAL_HOURS` | `12` | минимальный интервал авто-бэкапов |
| `SAT_BACKUP_MAX_PER_DAY` | `2` | предел авто-бэкапов за сутки (`0` — без предела) |
| `SAT_BACKUP_KEEP` | `20` | сколько последних копий хранить |

## Переезд с уже накопленными задачами

1. На старой машине: `npm run db:backup` (или скопируй `data/tracker.db` целиком).
2. Перенеси файл бэкапа в `data/backups` новой копии.
3. Восстанови: `npm run db:restore -- --file tracker-2026-10-19_15-04-12.db` (сервер должен быть остановлен).
4. Проверь: `npm run doctor` и `npm run db:stats`.

## Типовые проблемы

| Симптом | Причина и решение |
|---|---|
| `node:sqlite` не найден / ошибка импорта | Node < 22.5 — обнови Node |
| MCP-клиент пишет «сервер не отвечает» | не установлены зависимости: `npm install --omit=dev`; диагностика — `node scripts/mcp-launcher.mjs` вручную |
| Агент не видит задачи | правила из `AGENT_INSTRUCTIONS.md` не добавлены в инструкцию проекта |
| Порт 4317 занят | `SAT_PORT=4318 npm start` |
| В базе пусто после переноса | база создаётся в `data/` новой копии; старые задачи нужно импортировать или восстановить из бэкапа |
