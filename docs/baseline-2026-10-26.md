## Rules proposed for future runs

These are recommendations, not implemented enforcement:

1. Separate audit-only runs from implementation runs. Audit mode must not edit code or enter developer stages.
2. Record repository root, base SHA, working-tree state and CodeGraph root before dispatch. Refuse a run when required source changes are uncommitted or the index points to another checkout.
3. Pass a bounded handoff: goal, acceptance criteria, base/result SHA, changed paths, exact check results and unresolved issues. Store full logs as artifacts rather than embedding them into later prompts.
4. Use fresh stage sessions with a handoff budget and independently enforced per-stage and per-run token/cost limits. Instructions alone are not a hard limit.
5. Treat missing dependencies as an environment failure. Do not spend another model revision repeating unchanged checks.
6. Expose a concise completion matrix and distinguish committed, uncommitted, tested and unverified work.

This audit did not restart automation or change SAT-1 status.
