# SAT-26: информативный компактный журнал

Предыдущий whitelist удалял не только содержимое файлов, но и имена инструментов/команд. Из-за этого события были бесполезны для диагностики реального SAT-10.

Теперь показываются:

- MCP server/tool и стадии вызова/завершения/ошибки; аргументы и результат не копируются.
- Начало native команды и краткая команда с exit code после завершения.
- Команды setup/checks worker с безопасным описанием вместо безымянного exit code.
- Число тестов при точном успешном сообщении compact reporter; при ошибке — релевантная диагностика.
- Пути изменённых файлов без patches и исходников.

Inline программы, длинные/многострочные shell-сценарии скрываются; вместо тела выводятся имена распознанных действий. Короткие обычные команды отображаются, значения известных credential flags маскируются. Это формат журнала, не изоляция секретов от самого CLI. Исторические события, из которых метаданные ранее удалены, восстановить этим изменением нельзя.

Проверены имена команд/MCP, ошибки, скрытие исходников, сохранение result/usage, legacy decoder и headless UI (фильтры/копирование/скачивание/скролл/адаптивность). Фактический SAT-10 отдельно остановился после успешной разработки по накопленному входу, включая кеш: исходный коммит 46ae04f сохранён. Лимит не повышался, developer повторно не запускался.
