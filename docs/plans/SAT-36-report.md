# SAT-36: причина остановки и накопленный бюджет

В основной панели очереди видны использованное время всех попыток, общий лимит и остаток. Для failed/interrupted/merge_blocked причина остановки показана над журналом. Диагностика исчерпания времени/токенов/вызовов переведена на русский. При исчерпанном бюджете продолжение недоступно; кнопка настройки только открывает форму.

Детали запуска теперь включают авторитетную QueueItem-проекцию с теми же правилами доступности действий, что и очередь. Выбранный запуск сравнивает свежесть detail и snapshot: после выхода из активной очереди он больше не остаётся визуально running.

Проверки: 150 unit tests passed; typecheck; build server/web; headless scripts/verify-queue-budget.ts — running→failed, видимая причина, остановившийся счётчик, отсутствие POST при открытии редактора, размеры 390/844, отсутствие pageerror. Проверки используют временное синтетическое хранилище и не запускают модели.

Развёртывание требует обновления API и UI вместе. Работающий SAT-352 не перезапускался ради публикации этой правки; активную worktree и лимиты эта фича не меняет.
