# SAT-30 — подключение перед выбором папки

Причина: offline-кнопка «Подключить и выбрать папку» копировала bootstrap
в буфер и лишь показывала сообщение в большом окне. Без локального host
браузер не может сам открыть системный диалог через локальный процесс.

Теперь кнопка сразу открывает отдельный PrimeNG диалог с объяснением,
видимой командой PowerShell, требованиями, состоянием ожидания, повторным
копированием и отменой. При отказе clipboard команда остаётся доступной
и выделяется в этом диалоге. При подключении host диалог закрывается,
выбор папки вызывается ровно один раз. Отмена прекращает ожидание.
Путь проекта без выбора не меняется.

Уточнён текст подключения: host запускается в фоне, исполнителем управляют
кнопки в UI. Online Windows использует существующий системный picker
на компьютере host; на других ОС остаётся обзор каталогов.
Первый запуск локального host из обычного браузера не добавлялся:
без установленного локального моста это недоступно.

Проверки: 142 теста npm test, build server/web, typecheck.
Headless scripts/verify-automation.ts проверяет видимый диалог и команду,
отказ clipboard, отмену/повтор и автоматический вызов picker после подключения,
отмену picker и сохранность выбранного пути. Picker в тесте подставной —
автоматического физического выбора папки в системном окне не выполнялось.
