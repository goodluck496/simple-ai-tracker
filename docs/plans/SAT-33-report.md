# SAT-33 — пакетная постановка задач

В шапке появилась кнопка «Группа задач», открывающая вкладку Запуск.
Пакетный режим также выбирается в общей вкладке Запуск.
PrimeNG MultiSelect с поиском, выбор доступных (до 50), очистка и удаление
отдельных задач. Список показывает причины блокировки; при изменении статуса
они обновляются. Можно выбрать только аналитика или любой существующий
набор ролей и порядок. Для всех задач применяется один показанный snapshot
проекта вместо task overrides; defaults автоматически не сохраняются.

Для каждой задачи создаётся отдельный AgentRun. Метод enqueueBatch,
REST POST /api/automation/batch и tracker_automation_enqueue_batch используют
один сервис. Вся группа создаётся в одной DB-транзакции: дубли ID, вопросы,
активная задача, неизвестный ID, отсутствие плана/проверок для записи кода
откатывают все новые runs. Граница группы — 50 задач.

requestId (UUID) и fingerprint сохраняются атомарно с IDs запусков.
Повтор неизменённого запроса возвращает прежние runs, в том числе после
завершения анализа; другой payload с тем же ключом отвергается.
UI сохраняет ключ при повторе неудачного запроса.

Проверки:

- batch-enqueue.spec.ts: atomic rollback, границы и повторы ID, developer
  без плана, MCP enqueue, idempotency, активный дубль, неизвестный ID,
  неизменность настроек, повтор после завершения аналитики.
- verify-batch-launch.ts: вход из шапки, MultiSelect, analyst-only без checks,
  изменение eligibility на вопросы, блокировка/удаление, ошибка и повтор
  с тем же ключом, exact queue snapshot, сохранность defaults, 390×844/844×390.
- verify-card-launch.ts и verify-task-teams.ts: прошли.
- Полный npm test: 144 passed.
- Server/web build и typecheck: прошли.
- Скриншот группы сохранён в dist/acceptance/batch-launch.png.

Проверки выполнялись на синтетическом хранилище и CLI без реальных моделей.
Реальные группы задач агентом не отправлялись. После постановки задачи
исполняются существующим worktree-конвейером, с его лимитами параллелизма
и бюджетами каждого запуска. Это не обещание выполнения всех задач моделями.
