# SAT-20 — popup добавления роли

Причина: p-select добавления роли использовал локальный overlay внутри
.p-tabpanels с overflow:auto. Список попадал в обрезаемую прокручиваемую
область рядом с фиксированным футером; прокрутка контейнера закрывала popup.

Добавлены appendTo="body" и scrollHeight="12rem". PrimeNG позиционирует
popup в свободной области viewport, список прокручивается внутри overlay.
Обработчики глобального scroll не переопределялись.

Регрессия в scripts/verify-task-teams.ts сначала воспроизвела дефект на
прежней сборке. После исправления на 1440×1000 и 390×844 проверены:
trigger у нижнего края панели, отсутствие popup внутри clipping-контейнера,
неизменный scrollTop модалки, popup в viewport, реальная прокрутка списка
колесом без закрытия, выбор роли. Остальной сценарий выбора команды,
порядка запуска и immutable snapshot также прошёл.
Финальный скриншот popup просмотрен.

Сборка web и Docker прошли. Первый npm test: 141 passed, 1 failed —
таймаут подтверждения остановки executor в execution-supervisor.spec.ts.
Отдельный повтор этого теста прошёл; код supervisor не менялся.
Финальный полный повтор: 142 passed.
Реальные задачи и модели в регрессии не запускались.
