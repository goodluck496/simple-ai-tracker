# SAT-34 — видимая активность длительных операций

В карточке выполняющегося запуска и над журналом выбранной задачи отображаются
ответ worker, анимированная точка/PrimeNG indeterminate progressbar,
текущая фаза, её длительность и возраст ответа. Таймер обновляется раз в секунду
без новых событий команды. Он привязан к serverTime и monotonic performance.now,
поэтому разница часов браузера/сервера не искажает показания.

В подробностях — возраст последнего события, объяснение неопределённого
прогресса и процент завершённых этапов агентов (из реального stage/length).
Процент установки npm/копирования не выдумывается.
Heartbeat означает связь с worker, а не доказательство продвижения subprocess.
После 2 минут без событий показывается предупреждение, при живом heartbeat
ожидание остаётся анимированным. При старом/отсутствующем heartbeat анимация
останавливается. При ошибке queue HTTP или отсутствии нового snapshot 15 секунд
(включая зависшие HTTP-запросы) отображается неподтверждённое состояние,
анимация выключается. Восстановление HTTP автоматически возвращает индикацию.
Завершённые/остановленные задачи не анимируются.
prefers-reduced-motion отключает pulse и анимации pseudo-elements progressbar.

Обновление только UI: нет новых stdout-потоков в промпты моделей, heartbeat
протокол/бюджеты/lease worker не менялись. Проверка waiting-slot health перенесена
после проверки свежести heartbeat, чтобы устаревший запуск не объявлялся живым.

Проверки:

- queue-activity.spec.ts: active/quiet/stale/disconnected/idle, stage ratio,
  clamp, некорректные даты и формат длительности.
- verify-queue-activity.ts: setup без вывода, таймер, indeterminate,
  реальные stage проценты, quiet, потеря heartbeat, HTTP failure/hang,
  recovery, завершение, reduced motion, 390×844 и 844×390.
- verify-run-console.ts: прошёл, журнал/фильтры/scroll/copy/download
  и отзывчивость layout сохранены.
- npm test: 145 passed; build:web и typecheck прошли.
- Финальный скриншот просмотрен.
