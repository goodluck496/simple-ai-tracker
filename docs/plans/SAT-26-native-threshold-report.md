# SAT-26: порог действий native CLI

SAT-10 остановился с `Agent tool-call limit exceeded (24)` после точечных чтений и начала правок. Количество инструментов само по себе не измеряет прогресс или зацикливание.

NativeAgentRunner теперь считает уникальные события инструментов, но превышение прежнего порога только один раз пишет компактное предупреждение. Оно не прерывает процесс и не вызывает модель заново. Внешний AbortSignal, таймаут этапа, общий бюджет времени/наблюдаемых токенов и число проходов остаются действующими. Отдельный управляемый цикл Model API не изменён. Эвристическая оценка полезности действий не вводилась.

Регрессия: завершённый ответ после превышения порога, одно предупреждение при нескольких последующих действиях, внешняя отмена. Сфокусированные тесты: 3 passed. Полный набор: 131 passed. Typecheck и сборки server/web прошли. Фактическое продолжение SAT-10 фиксируется в карточке отдельно; эти проверки не доказывают выполнение SAT-10.

Для применения к существующему запуску достаточно обновлённого host worker. Настройки/ветка/правки SAT-10 сохраняются. Контейнер API пересоздавать не требуется.
