# SAT-35: промежуточные результаты и продолжение этапа

## Результат

Worker принимает короткие StageNote от любой роли через runtime-mailbox `.sat/stage-note.json` и сохраняет их в карточку через MCP `tracker_automation_checkpoint`. Запись привязана к действующим lease и attempt. Повторы не дублируют комментарии. Исходники, diff и многострочный вывод отклоняются; до 3000 символов, до шести пунктов в списке. Журнал содержит факты, завершённые шаги, файлы/символы, проверки и следующий шаг. Его отсутствие в финальной заметке не означает завершение: это подтверждает только outcome и worker-проверки.

Каждая роль получает инструкцию сохранять результат после локализации, законченного шага и примерно каждых пяти инструментов. Один runtime-журнал заменяет двойную запись в stage-note/work-progress. Worker публикует его периодически и при завершении/ошибке. После жёсткого выхода процесса невысланный mailbox того же контекста восстанавливается до новой модели.

В run сохраняется последний checkpoint и conversation ID Antigravity. Ключ включает run, этап, ревизию, задачу, настройки/профиль, требования, HEAD и worktree. Продолжение того же этапа использует `--conversation`; другая роль/контекст получает новый разговор. Ни глобальное `--continue`, ни настройки аккаунта не меняются. В новый prompt идут текущие требования и последний ограниченный checkpoint; после нового run доступна последняя запись из карточки. Прежние заметки — подсказки, не доказательство состояния кода. Код всегда читается из текущей worktree.

У Antigravity исправлен обход счётчика инструментов. Уникальные step_index считаются один раз; превышение настроенного наблюдаемого порога останавливает CLI без скрытого retry. Это наблюдение stream, не запрет исполнения инструмента на уровне ОС. Последний checkpoint и worktree сохраняются.

## Реальная проверка

`scripts/verify-antigravity-worker.ts` запускается только с явным `SAT_LIVE_ANTIGRAVITY=1`, модели не входят в npm test. Создаёт временный Git и синтетический tracker через настоящий MCP tool registry и PipelineWorker; пользовательские карточки и исходники проектов не меняет.

1. Реальный Antigravity developer: прочитал инструкции/файл, записал checkpoint до правки, изменил a.txt 0→1, выполнил node check.cjs, вернул schema outcome. Worker независимо проверил результат, создал коммит в worktree и перевёл задачу в review. Основной checkout не изменён.
2. Режим `SAT_LIVE_RESUME=1`: worker намеренно остановлен сразу после durable checkpoint. Новый worker продолжил ту же native conversation ID, внёс правку, проверка прошла, итог review. Первый вызов около 40 с, продолжение около 39 с. Новых автоматических попыток не было.

Живая проверка выявила два дополнительных дефекта: финальная заметка без nextStep отклонялась, а итоговое usage не заменяло частичные записи из-за другого reportedRequests. Исправлены и покрыты регрессиями. Оплачиваемые проверки после этих исправлений не повторялись без необходимости.

CLI возвращает итоговые токены накопительно по conversation. Наблюдённые 131335 input включали первые 41344; продолжению относятся 89991. Старое суммирование давало неверные 172679. Теперь attempt привязан к session ID, при продолжении из итоговой сводки вычитаются уже учтённые значения. Cached input учитывается один раз. Проверены официальный пример с кешем и метаданные реального теста. Первая оборванная попытка остаётся помеченной частичной.

## Проверки и пределы

Unit/worker: валидация текста и запрет кода, пределы размера, dedup, lease/attempt fencing, сериализация публикаций, crash recovery, передача checkpoint/session новому worker, изоляция ролей, split JSON stream, счётчик инструментов, терминальная сводка и отсутствие двойного учёта при resume. Typecheck, server/web build и полный npm test.

Это подтверждает работающий малый цикл и сохранение результатов. Не подтверждает исправление SAT-352, успешность любого большого анализа или малый расход токенов: тестовый разговор всё ещё потребовал около 131 тыс. входных токенов. SAT-352 автоматически не запускалась; дополнительные лимиты пользовательским задачам не выдавались.
