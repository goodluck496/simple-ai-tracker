# SAT-4: консоль и компактный контекст
1. Добавить shared-парсер журналов: JSONL/обычный текст, частичные записи между порциями, сообщения, команды, stdout/stderr, exit code, уровни, ANSI; без сырых транспортных обёрток и дублей.
2. В UI сделать консоль с переносами, фильтрами уровня/этапа, копированием, автоскроллом только у нижнего края, действием «К последним строкам», явным ограниченным окном и отдельным raw-просмотром. Сброс состояния при смене запуска/пространства; сохранить текущий polling.
3. Устранить отрезание JSON внутри worker progress; использовать ограниченные порции с сохранением границ и явной меткой при ограничении накопленного вывода.
4. Ограничить handoff prompt: краткие комментарии/feedback/diff, без полных журналов; явные инструкции делать шаги плана, не пересказывать процесс, сохранять успешный stdout в артефакт и сообщать одну строку результата, при неуспехе — существенный trace. Подробный пользовательский лог не удалять ради сокращения prompt.
5. Unit-тесты парсера/границ/handoff и изолированный Playwright-сценарий консоли (raw, фильтры, Unicode, копирование, scroll, смена запуска). Полный test/typecheck/build, отчёт, отдельный коммит, review. Без платных запусков и без интерактивного shell.
