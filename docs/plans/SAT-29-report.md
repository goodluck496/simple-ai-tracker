# SAT-29 — окружение worktree до вызова модели

Прямой режим вынесен в SAT-28 (backlog), в этом изменении не реализован.

Общий registry runner теперь выполняет preflight перед реальным вызовом агента,
включая агента разрешения конфликтов. Восстановленный checkpoint по-прежнему
не вызывает модель повторно. Worker загружает существующие корневые
AGENTS.md/AGENT_INSTRUCTIONS.md/CLAUDE.md и выбранные по роли инструкции/скилы
из docs/agent-environment.json. Файлы читаются полностью в пределах общего
лимита 48000 символов; обязательные требования не усекаются.
Пути проверяются через realpath, внешние junction/symlink запрещены.

Для явно перечисленных stdio MCP выполняются initialize и постраничный
listTools, проверяется allowlist инструментов, затем соединение закрывается.
Есть таймаут 15 секунд, отмена и освобождение транспорта.
Прикладные инструменты на preflight не вызываются.
Переменные берутся из того же очищенного окружения задачи, что использует
runner: секреты и host routing не попадают в журнал/квитанцию.
Codex получает command/args/cwd/env_vars/enabled_tools.
Другие runner при обязательном проектном MCP блокируются до модели.
Сторонние MCP аккаунта Codex остаются отключены.

В журнале — путь, короткий SHA256, размер, роль, проверенные MCP/tools.
В .sat/environment-<role>.json — полные хеши и время проверки без тел/секретов.
Фактические MCP-вызовы отображаются существующими событиями native runner.
Инструкция настройки: docs/project-agent-environment.md.

Проверки:

- Сфокусированные тесты: 5 passed.
- Полный npm test: 141 passed.
- npm run typecheck: passed.
- npm run build: сервер и Angular собраны.
- Реальный локальный Codex mcp get (без модели) принял env_vars и enabled_tools.
- MCP fixture — отдельный настоящий stdio процесс: initialize, две страницы
  listTools, проверка отсутствующего инструмента и недоступного executable.
- Тест PipelineWorker использует отдельные Git worktree и CLI fixture:
  выбранные developer/reviewer получают проектную инструкцию и квитанцию;
  обязательные checks не обходятся, невыбранные роли не вызываются.

Ограничения: это не приёмка реальной платной задачи моделью и не доказательство
соблюдения скила агентом. HTTP MCP и управляемый проектный MCP для
DeepSeek Harness/Antigravity пока не реализованы. Доступность существующих
встроенных tracker/CodeGraph остаётся на прежнем пути; новая MCP-проба
касается серверов из проектного профиля. Конечный статус реализации review,
done выставляет пользователь.
