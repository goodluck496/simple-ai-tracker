# SAT-31 — переименование пространства

Рядом с селектором пространства добавлена PrimeNG кнопка-карандаш.
Открывается PrimeNG диалог названия с сохранением, отменой, блокировкой
пустого значения и сообщением об ошибке. При сбое диалог остаётся открытым,
можно повторить сохранение. Список обновляется без переключения пространства.

POST /api/workspaces/:name/rename меняет только label. Стабильное имя/ID,
пути SQLite/бэкапов, текущий контейнер и привязки worker не меняются.
Поддерживается переименование Default. Название: 1–100 символов,
пробелы по краям удаляются, управляющие символы запрещены.

Проверки: сфокусированный workspace-rename.spec.ts; полный npm test —
142 passed; build server/web и typecheck. В synthetic API regression
проверены ошибки, два пространства, сохранность задач/путей/ID и повторное
открытие приложения. Headless проверка переименования, пустого значения,
ошибки/повтора и reload добавлена в scripts/verify-automation.ts.
Реальные пространства не переименовывались.
