# SAT-17 — контекст и бюджет

В историческом запуске SAT-9 наблюдалось 840101 cumulative input, включая 778752 cached input; разница 61349. Это сумма входов, а не размер одного окна и не денежная стоимость. Запуск предшествует нынешней изоляции MCP. Сохранённые 14 команд содержали 67917 символов вывода; две крупнейшие — 36421 символ. Эти данные объясняют повторную передачу истории, но не доказывают единственную причину расхода.

Теперь роли получают точный нумерованный work order, список изменений и краткие проверенные результаты предыдущего этапа. Полный diff предназначен reviewer. Progress hints сохраняются на диске, проверяются по версии требований и не считаются доказательством выполнения. Успешный npm test печатает одну строку; ошибки содержат trace. Codex получает tool_output_token_limit=1500 и наблюдаемый предел инструментов этапа (24 по умолчанию). Лимит CLI не является строгой финансовой гарантией.

Очередь объясняет cumulative input, кеш, unknown/partial usage и лимит. Финальное usage CLI больше не прерывает уже готовый ответ: он сохраняется в checkpoint до отчёта о бюджете. Следующий вызов при исчерпанном бюджете запрещён; автоматического увеличения нет.

Проверено: полный набор 125 тестов; отдельно регрессия live/time/terminal budget после последней правки; сборка server/web; typecheck; headless verify-queue. Платные модели и SAT-9 не запускались. Сравнительный процент экономии не измерялся. Декомпозиция и бюджет продолжения расширяются отдельно в SAT-18.
