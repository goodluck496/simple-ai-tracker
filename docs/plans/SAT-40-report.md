# SAT-40: вернуть редизайн модалки агентов

Причина регрессии в production: при сборках SAT-37/38/39 пользовательские незакоммиченные изменения четырёх UI-файлов намеренно исключались из export index. Исходники редизайна оставались на диске, но в Docker попадала прежняя модалка. Пользователь подтвердил необходимость вернуть свой интерфейс.

Включены существующие файлы app.component.html и automation-panel.component.html/scss/ts без переписывания дизайна: боковая навигация, крупная модалка 1280px/92dvh, оформление секций, управление областью настроек и сохранение внизу панели. Сохраняются исправления SAT-37/38/39. Каталог debug не включён.

Проверено: чистая production-сборка server+web; headless Playwright на синтетическом хранилище — четыре раздела навигации, фиксированный размер после окончания входной анимации, фон футера, успешное сохранение настроек. Дополнительно verify-integrated-workflow: запуск developer+tester без готового плана, trusted checkbox/persistence/snapshot/queue, создание карточки и узкий экран. Ошибок браузера нет; платные модели и реальные задачи не запускались. Финальный скриншот agent-redesign.png просмотрен один раз: пользовательский редизайн присутствует. Backend-код не менялся, полный серверный suite повторно не запускался.
