Сохранённые изменения из worktree перенесены в основную ветку без изменения оригинала. Проверены и дополнены dequeue только queued, отдельный cancel running, сохранение задачи/журнала, уведомление об успехе и русская ошибка конфликта.

Проверки: сфокусированные серверные тесты PASS; полный npm test — 90 passed / 0 failed; typecheck PASS; server+web build PASS. Изолированный scripts/verify-queue.ts PASS: кнопка на карточке и в деталях, busy/повторный клик, выигравший claim возвращает 409 без остановки процесса, обновление UI, история/requeue/resume/restart, 390/844/1440px, отсутствие неожиданных ошибок браузера. Тест двух пространств с одинаковым task ID и двух соединений SQLite проверяет обе последовательности dequeue/claim; транзакция BEGIN IMMEDIATE исключает одновременную запись.

В старом браузерном сценарии исправлены два неверных ожидания: claim после отмены всех запусков и «Остановить» для нового queued-запуска. Это ошибки проверки, которые ранее скрывались за отсутствующей сборкой.
