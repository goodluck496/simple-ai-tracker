# SAT-20 — строки агентов на вкладке «Запуск»

Выбор исполнителей и порядок этапов объединены в один список. В каждой строке
PrimeNG checkbox, номер выбранного этапа, роль, runner/модель и PrimeNG кнопки
вверх/вниз. Выбранные агенты отображаются в порядке pipeline, выключенные ниже.
Нажатие на название переключает связанную галку. Недоступные перемещения
заблокированы. На узком экране метаданные компактно располагаются внутри строки,
длинные названия сокращаются; полный текст доступен через title.

Сохранены выбор отдельных ролей, область задачи/проекта и snapshot запуска.
Дублирующий нумерованный список удалён.

Проверки: npm run build:web; 141 тест npm test; headless
scripts/verify-task-teams.ts — checkbox и reorder в своей строке, отсутствие
дублирующего списка, выбор developer/reviewer/analyst, точный snapshot очереди,
сохранение/сброс настроек задачи, фиксированные размеры модалки и непрозрачный
футер, отсутствие горизонтального переполнения при 390×844 и 844×390.
Финальный скриншот просмотрен. Проверки используют синтетическое хранилище,
платные модели и реальные задачи не запускались.
